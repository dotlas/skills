# Community Skills

Open source skills by external authors, vendored for internal use at Dotlas.
These are not Dotlas-authored — for skills built by Dotlas, see the
[custom catalog](../custom/).

## Common

| Skill | Description |
| --- | --- |
| [caveman](./common/caveman/) | Compress responses ~65% with terse caveman-speak while keeping full technical accuracy. |
| [grill-me](./common/grill-me/) | Relentless interview that sharpens a plan or design by stress-testing every assumption. |
| [grill-with-docs](./common/grill-with-docs/) | Like grill-me, but produces ADRs and a glossary as the session progresses. |
| [grilling](./common/grilling/) | Adversarial questioning mode for stress-testing ideas and decisions. |
| [handoff](./common/handoff/) | Compress a conversation into a compact pickup document for the next agent or session. |
| [teach](./common/teach/) | Teach a concept or skill within the current workspace as a structured learning mission. |
| [write-a-skill](./common/write-a-skill/) | Scaffold new skills with correct structure, progressive disclosure, and bundled resources. |
| [writing-great-skills](./common/writing-great-skills/) | Reference for the vocabulary and principles that make a skill predictable and well-formed. |
| [writing-guidelines](./common/writing-guidelines/) | Review docs and prose against Vercel’s writing style guide. |
